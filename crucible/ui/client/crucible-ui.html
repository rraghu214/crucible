What is an apply probe?
The apply probe performs a real end-to-end test: it pushes a trivial change to perftest_sandbox, confirms the target restarts and passes its readiness probe, reads the property back, then reverts. It exercises deploy → verify → revert exactly as a campaign will.

The target service will restart once. Run this before the first campaign on any new environment.
Manual overrides
If deploy or restart is not automated, declare it here. The campaign will block with instructions when a manual step is reached and record it on the manifest.

Core protections
These cannot be disabled — they exist because disabling them reintroduces a specific past failure
SLA is read-only
The AI cannot raise its own goalposts. The p99 ceiling and error budget you set are locked for the lifetime of the run. Enforced as Policy memory and a protected file path — weakening either independently defeats both.
Always enforced
Load profile is read-only
Fewer users is not a fix. Reducing load to hit the SLA destroys comparability across runs.
Always enforced
Writes only to perftest_sandbox
Crucible never writes to main, master, develop, trunk, release/*, hotfix/* or the base branch. Checked when the profile loads, not just at push time.
Always enforced
No cross-provider failover
Model is pinned per campaign. A campaign whose experiments were diagnosed by different models is not internally comparable. CRUCIBLE_GATEWAY_FALLBACK_PROVIDERS stays empty.
Always enforced
No force-push
Reverting means deploying an earlier commit, never rewriting history. Force-push would destroy the experiment history that every manifest depends on.
Always enforced
Configurable rules
Require human approval before every change
Semi-automated mode. Turn off only in Fully Automated mode with pre-approved properties.
Auto-revert on SLA miss
If a change fails to improve p99 or worsens error rate, Crucible redeploys the last good commit automatically.
Abort if host CPU steal exceeds threshold
A noisy neighbour on shared VCPUs means measurements are about someone else's workload. Default 5%; Oracle free tier uses 10%.
