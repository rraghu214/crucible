## Steps (~2 hours)

| # | Do | Pass when | What it shows |
|---|---|---|---|
| 1 | **Results**, then **History** | Real run ids (e.g. `run-20261017-201413`), not TR-003 | **Manifests on disk**: every result is a file |
| 2 | New Test Run → Target & Repo → Knowledge Docs: drop `PERF_LAB_PRODUCT.md` → **Upload & index** | Chip: queued → indexing… (a few minutes; keep going) | **RAG ingestion**: background queue, chunking, pinned embedder, separate index |
| 3 | While it indexes: **Guardrails** | Core protections, allowed properties and bounds visible | **Guardrails**: SLA locked twice (path guard + Policy memory); SKILL.md informs, profile.yaml grants |
| 4 | Chat says "indexed — N chunks" → Live AI **ON** → *How many requests must Micrometer meters be initialised within, and how long may PerfLab take to start?* | "10 requests", "60 seconds", a **Sources:** line | **Grounded retrieval with citations**; facts read from disk |
| 5 | Goal & SLA → **✨ AI suggestion** | Fields fill; noise floor 2.08% stays read-only | **Structured LLM output, validated** before use |
| 6 | Scenarios → **Advisory** (keep **one** scenario) → Budget → Review → **🚀 Launch** | Jobs shows `crucible run --advisory …` | **Plan before apply**: the exact diff Launch writes; budget foregrounds wall clock |
| 7 | While it runs (~10 min): **Preflight → Run checks**, then **Benchmarks** | Read-only checks pass; LUCKY quadrant visible | **Evals**: replay vs live; diagnosis scored apart from outcome |
| 8 | Advisory done → chat: *Why did you rank #1 above #2?* | Names the run, `2 -> 20`, pending evidence; calls 140 ms a **prediction** | **The agent explains its own trace**; prediction ≠ measurement |
| 9 | Wizard → **Semi-Automated**, experiments **2** → Launch | **Active** shows ● LIVE within ~5 s | **PDMA loop**: perceive → memory → decide → act |
| 10 | Approval gate → read the diff → **Approve** | "Change applied — measuring now" | **Human-in-the-loop**: approval bound to the exact diff; deploy verified by read-back from the target |
| 11 | *(Optional)* mid-run: raise p99 → **💾 Save changes** | Pauses at the next experiment; Resume records an amendment | **The operator stays in control**; every edit is audited |
| 12 | Run ends → **Results ↺** → chat: *Why was experiment 1 kept in &lt;run-id&gt;?* then *tell me about zz-run-77* | MEASURED before → after quoted; zz-run-77 reported **not on disk** | **Principle 1**: measured, not claimed; **principle 2**: says what it can't see |
| 13 | Box B: `ls ~/.crucible/` and `python3 -m json.tool ~/crucible/results/<run-id>.json \| head -40` | `memory.sqlite`, `knowledge-index/`; manifest names the model, commit, approvals | **Memory taxonomy** + reproducibility |
